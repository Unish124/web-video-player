Make it your default video player (Windows)

After this, double-clicking a video on your laptop opens it in videoplayer.unish.info.np.

  1. Open the site in Chrome or Edge and press Set as default video player on the start screen, then Install app. You can also use the browser menu: Install app in Chrome, or Apps → Install this site as an app in Edge.
  2. Right-click any video file, choose Open with, then Choose another app. Select Local Video Player, tick Always use this app and press OK.
  3. To cover every video type at once, open Windows Settings → Apps → Default apps, search for .mp4 and pick Local Video Player. Repeat for .mkv, .webm, .mov, .avi and .m4v.
  4. From then on, opening a video launches the app and plays it. Opening more videos adds them to the same window's playlist.

A website cannot change your Windows defaults by itself, so step 2 or 3 has to be done once by you. File opening needs a Chromium browser on Windows; Firefox and Safari cannot register as a file handler. Whether a video plays also depends on its format: MP4 (H.264), WebM and similar work best.
